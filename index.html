Repeat a button click.
On your own terms.

A lightweight bookmarklet-based auto clicker. Open the website you want to use, activate the bookmarklet, choose a button, and control the repeat interval.

1. Choose your website

This opens the site in a separate tab. The clicker is activated on that tab using a bookmarklet.

2. Create your Auto Clicker bookmark

Generate the bookmarklet, then save it as a browser bookmark. It runs on the active website tab, so it does not depend on the site allowing iframe embedding.

STEP 01Save a bookmark

Bookmark any page and name it “Clicker Bot”.

STEP 02Edit its address

Edit that bookmark and replace its URL with the copied bookmarklet text, including javascript:.

STEP 03Run on the target tab

Open your target website and tap the “Clicker Bot” bookmark to show the control panel.

Browser note: Bookmarklets are best supported in desktop Chrome/Edge. Some mobile browsers block JavaScript bookmarks or remove the javascript: prefix when saving. The GitHub Pages dashboard itself cannot directly control a different tab; the bookmarklet is the part that runs on the target page.

How the on-page clicker works

After launching the bookmarklet on a website, use the floating control panel:

ASelect button

Press “Pick button”, then click the page element you want to repeat.

BSet interval

Choose a delay within the range shown in the control panel and an optional click limit.

CStart / stop

Start, pause or stop. Press Escape to stop immediately.

The clicker uses the page's JavaScript click event. It cannot create a trusted physical tap, bypass CAPTCHAs, defeat site protections, or guarantee success on pages that reject automated events. Use it only where automated clicking is permitted.
